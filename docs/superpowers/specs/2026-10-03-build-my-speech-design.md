# BUILD MY SPEECH 児童画面 設計書

日付：2026-10-03

## 1. 先生向けの確認事項

NHE6 Unit 5「Where is it from?」で、児童が自分の持ち物を紹介するスピーチを作り、練習できる専用ページを作る。Google ClassroomにUnit専用リンクを貼って配布する。教師用Creatorは今回作らない。

- 右側は、既存「文で話そう」と同じカード・文構造の色分け・読み上げ・横スクロールの選択欄を使う。
- 左側には必須４項目、選択４項目、まとめページを置く。必須項目だけに番号を付ける。
- 国名は日本語検索、エリア名はリスト選択にする。
- 「持ち物のどこが気に入っているか」で、color / shape / design / size / texture / materialを選べる。
- design・size・texture・materialには、今回承認された４枚の画像を使う。textureとmaterialは別の選択肢とし、どちらも残す。
- 作文、自由入力、項目の採否、まとめの文順を、その端末・ブラウザ内へ自動保存する。
- 任意項目のチェックを外しても作文は消さない。まとめ・４線・発音練習は同じ内容と文順を使う。
- 次のUnitは、共通の仕組みに文と選択肢のデータを追加して対応できるようにする。

この文書は設計の確認用であり、動作確認済み・公開済みを意味しない。実装計画の確認と実装後のブラウザ検証は別工程とする。

### 既存画面を保つ境界

- SentencePlayerの公開APIであるmarkup / attach / settings / stop / openForCardsを維持する。
- 既存Unitの選択ロジックやSentenceUnitsの教材内容は、今回の共通化で変更しない。
- 新しい共通部品には、画像解決、ルート要素、選択通知、音声設定などを引数で渡す。新画面から既存画面の内部状態を直接書き換えない。
- イベント・タイマー・ResizeObserver・音声の停止は画面インスタンス単位で管理し、再描画やページ離脱時に破棄する。
- 短縮形長押し550ms、元に戻るまで3000msを共通定数とする。既存側の展開語や役割色は変えない。
- 共通化した部分は旧画面の回帰試験を先に用意し、挙動の一致を検証する。

## 4. ページとモジュールの構成

### 入口

公開時のURL形式は、grade56/build-my-speech.html?book=nh6&unit=5。

- 有効なUnitはプリセット登録表から解決する。nh6/5の分岐をエンジン内に散在させない。
- Unit未指定・未対応・不正な指定は「このUnitの教材はまだありません」と表示する。別Unitの作文を黙って開いたり上書きしたりしない。
- ヘッダーにNHE6 Unit 5 / Where is it from? / BUILD MY SPEECHを表示する。
- 児童ページには戻るボタンやホーム移動ボタンを付けない。
- Grade5&6の当該UnitのMake Sentencesには専用ページへのリンクを置く。教師設定画面は挟まない。

## 5. データモデル

Unit → Step → Sentence → Token/Slot参照という構造にする。P1～P9は要件の説明用で、内部処理は意味のあるstable idを使用する。

### Unitプリセット

- schemaVersion、unitId、book、unit、title。
- orderedStepsとslots、カード選択肢、入力ヒント、短縮形設定。
- 表示ラベルが変わってもstable idを変えない。
- Stepはrequired / optionalとsentences配列を持つ。１Step＝１文に固定しない。
- variantは同じStep内の文章構成を切り替える。切替前のSlot値を捨てない。

### Slot

- id、ownerStepId、inputType、defaultValue、choiceSetId、myWordsGroupId、allowMyWords、hint。
- 別Sentenceからの参照はslotIdとeditable:falseで表す。共有値の複製は作らない。
- 文構造の役割はToken側に置く。同じ語でも文中の役割と交換可能性を別々に定義する。
- 選択肢はid、label、image/cardRef、insertText、必要なspeechTextを持てる。
- labelは候補カード、insertTextは文カードと完成英文に使う。冠詞・前置詞・活用はデータに明示し、推論で付けない。
- 自由入力はプレーンテキストとして扱い、HTMLとして挿入しない。

### 状態

- unitId、schemaVersion、slotValues。
- stepVariants、optionalEnabled。
- sentenceOrder：採用解除中の文も含むstable sentence idの順序。
- myWords：語群別のユーザー語彙。
- drafts：Slot別の入力途中の文、検索途中の語など。
- UI状態：最後のStep、選択Slot、語群フィルター、読み上げ速度・音声設定、まとめの４線/発音モード。
- 全画面の解除・再表示で編集状態を失わない。ブラウザ再起動後にネイティブ全画面を自動要求しない。

未知のUnit、重複ID、参照先のないSlot、対応していない入力型は開発時検証で検出する。実行時にも安全なエラー表示にする。

## 6. NHE6 Unit5プリセット

初期値は授業用の例として置く。国と地域・近隣国の関係を自動判定する機能ではなく、児童が内容を確認して選ぶ。

| Step | 区分 | 文 | 入力・参照 |
| --- | --- | --- | --- |
| belonging | 必須1 持ち物 | This is my (belonging). | Picture Cards＋MY WORDS |
| origin | 必須2 生産国 | It's from (originCountry). | 国名検索、共有Slotの所有Step |
| region | 必須3 生産国が入っているエリア名 | (originCountry) is in (region). | 国名は参照のみ、regionはリスト |
| nearby | 必須4 生産国はどの国の近くか | It's close to (nearbyCountry). | 独立した国名検索 |
| acquisition | 任意 どうやって手に入れたか | 下記３variant | 人・購入場所 |
| favorite | 任意 持ち物のどこが気に入っているか | I like its (favoriteAspect). | Picture Cards＋MY WORDS |
| visit-origin | 任意 その国に行ってみたい | I want to go to (originCountry). | 国名は参照のみ |
| do-there | 任意 その国で～したい | I want to (action) (target) there. | 動詞カード＋自由入力 |

### 選択肢と初期値

- belonging：既存の衣類・身の回りのもの・文房具から画像のあるカードを用意。初期値T-shirt。This is my ... .として使える候補を選び、文に入る形は明示的なinsertTextとする。shoes → pair of shoes、scissors → pair of scissorsのような語句もデータで指定する。正しい挿入形が未定義の候補は出さず、エンジンが単複を推論して補わない。
- originCountry：初期値Japan。選択を変更するとregionとvisit-originの参照表示も同じ値に変わる。
- region：Asia / Europe / Africa / North America / South America / Oceania / Antarcticaを日英併記のリストで選ぶ。初期値Asia。MY WORDSによる追加も可能。国を変えても地域を勝手に推定・変更しない。
- nearbyCountry：初期値China。originCountryとは別の保存値。
- acquisition初期variantは「自分で買った」。購入場所の初期値はat a shopping mall、人はMy mother。
- favoriteAspect：color / shape / design / size / texture / material。初期値color。
- action：eat / see / visit / buy。初期値eat。
- target：MY WORDS入力。初期例sushi。入力例としてkoalas / the Eiffel Tower / a T-shirtも示す。
- 任意項目は初回すべて不採用。項目名を押せば編集でき、採用チェックとは独立する。

### acquisitionのvariant

| 意味 | 文 |
| --- | --- |
| 自分で買った | I bought it (purchasePlace). |
| 買ってもらった | (giver) bought it (purchasePlace). |
| もらった | (giver) gave it to me. |

purchasePlaceはat a shopping mall / in Kyoto / onlineなどの完成語句。画像が存在する候補には既存画像を使い、ない候補に無関係な画像を付けない。

giverはmother / father / friend / brother / sisterを既存カードから選び、insertTextをMy mother / My fatherなどと明示する。文中に入る完成語句は、選択した絵に対応するカードとして表示する。

### MY WORDSのヒント

- purchasePlace：「場所を表す語句を入力しよう。必要なら at / in なども含めよう。」
- favoriteAspect：「名詞を1語で入力しよう。」
- target：「何を？・どこを？を英語で入力しよう。」
- belonging / giver / regionも、それぞれの語句に合う短いヒントをプリセットで指定する。

## 8. 編集画面の操作

### 左メニュー

必須４項目だけ番号を表示。任意項目はチェックと項目名を別の操作領域にする。チェックはまとめへの採否だけを変更し、編集内容・variant・語彙を消さない。

Stepを開くと、そのvariantの最初の編集可能Slotを自動選択する。保存からの復元や全画面解除では、保存済みの有効な選択Slotを優先する。

### 右側

上部の役割ラベルは既存の７種類と色を維持する。Slotは太めの枠・薄い背景・選択枠で強調し、新しい役割色は追加しない。

- 固定カードは読み上げ、交換可能カードはSlot選択と読み上げ。
- 文全体の読み上げ、速度、カード音声ON/OFF、区切り読み、拡大率調整を既存由来の部品で提供。
- 参照だけのStepは選択欄を隠し、文章用の領域を広く使う。
- 文カードに長い国名・語句を入れても画像や文字を切らない。
- It'sやdon'tは通常１枚。長押し中だけ展開し、保存した英文自体は書き換えない。
- 短縮形は共通部品へ設定データで渡せる。今回のIt'sはIt / is、don'tはdo / not。将来のcannotなども既存側の設定を強制変更せず追加できる。

### 下段

左端に固定した「＋ ほかの言葉」、右側に横スクロールのPicture Cards。スクロールはカード列だけで、追加ボタンは常に見える。

ALL / MY WORDS / カテゴリの絞り込みは現在Slotに対応する候補だけを対象とする。入力型が国名・リストの場合は同じ下段領域を対応UIに切り替える。

## 9. MY WORDS、国名検索、リスト入力

### MY WORDS

入力パネルは見出し、英語入力欄、ヒント、追加する、キャンセルで構成。IME変換中のEnterで誤登録しない。

追加時に文章へ反映して保存し、同じUnit・同じ語群で再利用できるようにする。空白だけの入力は登録しない。文字数は200文字を上限とし、超過時には省略せず案内する。

削除には確認を付ける。既に作文に使用中の語をMY WORDS一覧から削除する場合は、「候補から削除しても、作った文は残ります」と伝え、文の選択値を文字列スナップショットとして維持する。語を差し替えるまで作文を消さない。

入力途中もSlot別に保存する。キャンセルはパネルを閉じるだけとし、未確定文を完成した文へ反映しない。再度開けば下書きを復元する。

### 国名検索

日本語・かな・カタカナ・英語・部分一致を既存WorldSearchで扱う。候補は日本語名と英文へ入る英語名を表示する。

Japan / Vietnamなどは既存表記を使用。英文用にthe U.K. / the U.S.などの表記を採用する国は、小さな明示的対応表でinsertTextを指定する。国名の綴りから冠詞を推論しない。

検索途中の文字と確定した国名は分離する。候補なしのときは案内を出し、確定値を消さない。名簿や位置情報は参照せず、国名検索のための外部通信は行わない。

### リスト入力

地域など、絵を必要としない候補を日英併記の選択リストとして表示する。選択するとその値を即反映・保存する。list型はUnit5専用処理にせず、他Unitからも使える入力部品とする。

## 10. 自動保存とリセット

保存キーはdekiru:build-my-speech:v1:nh6:5のように、機能・保存形式・book・unitで分離する。既存の語彙選択、保存セット、Interviewのキーは使用しない。

選択・variant・採否・文順は操作ごとに保存。入力途中のテキストもinputイベントごとにモデルへ反映して保存し、IME操作を妨げない。

- 新規端末はプリセットの初期状態から始める。
- 既存データは型・ID・長さを検証して読み込み、有効な値を優先する。
- ラベル変更や新Step追加では、同じIDの作文を維持する。
- JSON破損、未対応schemaVersion、保存不可を検出したら、元データを自動上書きせず、状態を案内する。破損・未対応データは退避に成功してから新状態を保存可能にする。退避もできなければメモリ内のみで継続する。
- 容量不足やアクセス拒否では「この端末に保存できません」と明示し、保存成功の表示を出さない。画面上の作文は残す。
- 正常保存後だけ「✓ この端末に自動保存」と表示する。
- 同一端末・ブラウザ・サイトで継続できる方式であり、別端末との同期や複数タブの同時編集解決は今回提供しない。

「↺ この文をもどす」は現在Stepだけを確認後に初期化する。現在Step所有のSlot、variant、入力下書きを対象とし、MY WORDS候補一覧、他Stepの選択、採用チェック、文順は残す。

originのリセットは共有originCountryを変更するため、参照先の文にも反映されることを確認文に添える。regionやvisit-originでリセットしても、参照元のoriginCountryは戻さない。変更可能値がないStepではリセットを無効にする。

## 11. まとめページ

カードを使わず英文テキストで表示する。必須Stepの文は常に採用し、任意StepはチェックONのものだけを表示する。

### 一つの文順

sentenceOrderを唯一の順序とする。通常表示・４線・読み上げは同じ解決済み文章列を受け取る。

- 初期状態は必須４文がプリセット順。
- 初めて採用された任意文は現在の並びの末尾へ追加する。既存文同士の順序を変えない。
- チェックOFFの文IDも順序データに残し、再ONで元の位置へ戻す。
- 同じ意味位置を持つvariantは同じsentence idを使用する。将来variantで文が増える場合も、残っている文の順序を維持する。
- 同一IDの重複や消滅した文IDを検証し、利用可能な文だけを描画する。

### 並べ替え

「文の順序を入れ替える」で１文単位のドラッグと↑↓ボタンを表示する。両方とも同じ並べ替え処理を呼び、毎回保存する。「完了」で通常表示に戻る。並べ替え中は不要な音声UIを隠す。

### ４線

「4線表記にする」で内容・順序を保ったまま切り替える。Andikaを同梱パスから読み込み、writing-fontおよびascender / x-height / baseline / descender相当のCSS変数で調整可能にする。

線色は上から水色・水色・濃いピンク・水色。長文の折り返し先にも４線を表示する。RuRiRuフォントへ差し替える箇所を一か所に集約する。

### 発音

「発音練習をする」で全文、１文ずつ、速度、停止の操作を表示する。４線と同時ONにできる。

既存の英語音声選択・速度・停止処理を再利用。音声資産が指定された語の再生に対応できる入口を設け、資産がない文やMY WORDSはSpeech Synthesisを使う。現行SentencePlayerが合成音声を使っている箇所に架空の録音音声を追加しない。

音声非対応・再生エラーでは案内を出す。画面遷移、再編集、再生停止、非表示化で古い読み上げとハイライトを止める。自動再生はせず、利用者の操作から開始する。

## 12. レイアウト・操作性

- Chromebook横画面の1366×768、1280×720を主な確認サイズとする。小さい表示では1280×600も確認する。
- ヘッダーの下を左右分割し、左メニューの高さを固定。右側は上部操作・下段選択欄に必要な高さを確保し、残りを文の領域へ割り当てる。
- 長い左メニュー、国検索結果、まとめの長文などは各領域内だけでスクロールする。基本画面でページ全体を縦スクロールさせない。
- 全画面はヘッダーを含むページ領域を対象にし、左メニューを隠す。ブラウザ全画面が使えない場合も同じアプリ内拡大表示を使える。
- 全画面解除、Escape、ウィンドウサイズ変更でStep・Slot・作文を保つ。
- 色は既存役割色を維持。黄色系の文字色を使わない。
- ボタンと入力欄にはラベルを付け、キーボード・タップで使えるようにする。選択枠・チェック・フォーカスを色だけに依存させない。
- ユーザー入力を必ずエスケープし、画像URLは同梱カード・承認画像に限定する。MY WORDSから画像URLやHTMLを実行しない。
