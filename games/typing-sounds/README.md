# ENGLISH TYPING operation sounds

Source: 効果音ラボ https://soundeffect-lab.info/
Terms checked on 2026-11-03: https://soundeffect-lab.info/agreement/
Used only as application operation sounds, not a sound distribution service.

Files supplied by the user in タイピング.zip. Audio content is unchanged;
filenames map each Japanese theme to the corresponding ASCII ID:
normal = ノーマル, cute = かわいい, sf = SF, japanese = 和楽器,
taiko = 和太鼓, pistol = 拳銃, sword = 剣.
Each theme has a fixed `-key.mp3` / `-enter.mp3` pair.
